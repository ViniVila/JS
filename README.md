# 📘 README – Exemplos Básicos em HTML + JavaScript

Este repositório contém **3 exemplos simples em HTML com JavaScript**, voltados para quem está começando a aprender programação web. Os códigos demonstram conceitos fundamentais como **entrada de dados**, **processamento**, **saída**, **uso de variáveis**, **funções** e **interação com o usuário**.

---

## 🧮 1. Somatória de Dois Números Inteiros

### 📄 Arquivo

`js03_soma.htm`

### 🎯 Objetivo

Ler dois números inteiros informados pelo usuário e exibir o resultado da soma.

### 🛠️ Conceitos Utilizados

* `window.prompt()` para entrada de dados
* `parseInt()` para conversão de texto em número
* Variáveis em JavaScript
* `document.write()` para saída de dados

### ▶️ Funcionamento

1. O usuário informa dois números por meio de caixas de diálogo.
2. O programa converte os valores para inteiros.
3. A soma é realizada.
4. O resultado é exibido diretamente na página.

### 📌 Observação

Caso o usuário digite algo que não seja número, o resultado pode ser `NaN`.

## 👋 2. Programa de Boas-Vindas

### 📄 Arquivo

`aula1.htm`

### 🎯 Objetivo

Capturar o nome do usuário e exibir uma mensagem personalizada de boas-vindas.

### 🛠️ Conceitos Utilizados

* `prompt()` para entrada de texto
* Variável para armazenamento de dados
* Concatenação de strings
* `document.write()` para exibição

### ▶️ Funcionamento

1. O sistema solicita o nome do usuário.
2. O nome digitado é armazenado em uma variável.
3. Uma mensagem personalizada é exibida na tela.

### 📌 Observação

Exemplo ideal para introdução à interação básica entre usuário e sistema.

## 🔗 3. Concatenação de Nome e Sobrenome

### 📄 Arquivo

`concatena.htm`

### 🎯 Objetivo

Concatenar nome e sobrenome digitados em um formulário e exibir uma saudação.

### 🛠️ Conceitos Utilizados

* Formulários HTML
* Campos `input`
* Funções em JavaScript
* Manipulação do DOM
* `window.alert()`

### ▶️ Funcionamento

1. O usuário digita nome e sobrenome nos campos do formulário.
2. Ao clicar em **Concatenar**, a função `concatena()` é executada.
3. Os valores são capturados a partir do formulário.
4. Nome e sobrenome são unidos em uma única string.
5. Uma mensagem de boas-vindas é exibida em um alerta.

### 📌 Observação

Este exemplo introduz o uso de **funções** e **formulários**, fundamentais para aplicações web.
